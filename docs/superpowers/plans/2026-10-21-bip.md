# Bip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Programa Windows (`bip.exe`) que escuta o leitor de código de barras em segundo plano enquanto o gerente bipa no UpSeller, grava rastreio + colaborador ativo e serve uma interface web local para trocar colaborador, pesquisar, registrar erro e ver relatórios.

**Architecture:** Um processo Python. Thread do `pynput` recebe teclas globais e passa para `ScanDetector` (lógica pura). Código detectado vai para `Servico`, que grava no SQLite via `Repo` e publica eventos em memória. Flask (servido por `waitress` em `127.0.0.1:8765`) expõe API JSON + página estática. A página faz polling de eventos a cada 500 ms e toca som via Web Audio.

**Tech Stack:** Python 3.14 (dev), pynput, Flask, waitress, sqlite3 (stdlib), winreg (stdlib), pytest, PyInstaller. Frontend: HTML + CSS + JS puro, sem build.

**Spec:** `docs/superpowers/specs/2026-10-21-bip-design.md`

## Global Constraints

- PC alvo: Windows 11 sem Python. Entrega: um único `dist/bip.exe` (PyInstaller `--onefile --noconsole`).
- Servidor escuta só em `127.0.0.1`, porta `8765`.
- Dados em `%LOCALAPPDATA%\Bip\bip.db`. Log em `%LOCALAPPDATA%\Bip\bip.log`.
- Filtro de bip: 10 a 30 caracteres `[A-Za-z0-9]`, terminado em Enter, todo intervalo entre teclas ≤ limiar.
- Limiar padrão 50 ms. Durante calibração: 300 ms. Calibração usa 3 amostras; limiar final = `clamp(round(maior_intervalo_das_amostras * 2), 25, 80)`.
- Rastreio normalizado para MAIÚSCULAS antes de gravar e comparar.
- Ao iniciar o programa, nenhum colaborador fica ativo.
- Texto da interface em português. Strings fixas: `Sem colaborador`, `Já registrado no {nome}`, `Peça errada`, `Já existe colaborador com esse nome`.
- Cor vermelha `#DC2626` é reservada para "Sem colaborador". Paleta automática de colaboradores (em ordem de criação, cicla): `#2563EB #16A34A #EA580C #9333EA #DB2777 #0891B2 #CA8A04 #92400E`. Som (Hz), mesmo índice: `440 554 659 784 880 988 1175 1319`.
- Sem backup, sem exportação Excel, sem acesso por rede.
- Datas gravadas como ISO local sem fuso (`datetime.now().isoformat(timespec="seconds")`).

## Review Focus

1. Leitor manda letra maiúscula com Shift: eventos de Shift não podem quebrar a sequência. Teste `test_modificador_nao_quebra_sequencia` (Task 1).
2. Colaborador ativo é desativado: bips seguintes devem cair em "Sem colaborador", não no desativado. Teste `test_desativar_ativo_limpa_ativo` (Task 4).
3. PC reinicia no meio do dia: programa não pode voltar com o colaborador de antes ativo. Teste `test_inicio_sem_ativo` (Task 4).
4. Relatório "semana" num domingo: semana vai de segunda a domingo, inclui o próprio domingo. Teste `test_semana_no_domingo` (Task 3).
5. Renomear para nome que já existe: erro 409 com mensagem, não exceção 500. Teste `test_renomear_duplicado_409` (Task 5).

  - `hoje() -> date` (`relogio().date()`, usado pelos relatórios da Task 5).
  - Thread-safe: `threading.Lock` em `processar_scan` e no acesso à fila.

### Task 6: Interface

**Files:**
- Modify: `bip/static/index.html`
- Create: `bip/static/app.js`, `bip/static/style.css`

**Interfaces:**
- Consumes: rotas da Task 5. Nada consome esta task.

Telas (abas no topo, a página abre numa janela estreita ao lado do UpSeller, mínimo 420 px de largura):

1. **Bipar** (padrão): fundo inteiro na cor do colaborador ativo, nome em fonte enorme (≥ 48 px, branco). Sem ativo: fundo `#DC2626`, texto `Sem colaborador`. Fileira de botões grandes, um por colaborador ativo (na cor dele) + botão `Sem colaborador`. Abaixo, últimos 20 bips: rastreio, nome (vermelho se sem colaborador), hora, ações `Mover` (select de colaboradores) e `Excluir` (`confirm("Excluir o registro {rastreio}?")`).
2. **Pesquisar**: campo com foco automático, busca ao digitar (debounce 300 ms, ≥ 3 chars). Cada resultado: rastreio, quem embalou, data/hora, botão `Peça errada` (abre `prompt` de observação opcional) ou `Desfazer erro` se já marcado, `Mover`, `Excluir`.
3. **Relatórios**: seletor `Hoje / Semana / Mês`. Tabela: colaborador, pacotes, erros, taxa (`%` com 1 casa). Clicar numa linha mostra a lista de pacotes daquela pessoa no período.
4. **Colaboradores**: criar (campo + botão), lista com renomear, trocar cor (`<input type="color">`), desativar/reativar. Checkbox "mostrar inativos". Mostrar a mensagem de erro do 409.
5. **Calibração** (sobreposição em tela cheia quando `estado.calibracao.calibrando`): `Calibração do leitor: bipe 3 pacotes no UpSeller` + progresso `{amostras}/3`. Botão `Recalibrar` no rodapé da aba Colaboradores.

Comportamento:
- Polling `GET /api/eventos?desde=<último>` a cada 500 ms. Cada evento: atualiza a lista e mostra um aviso por 3 s no topo (`mensagem`; repetido em amarelo `#CA8A04`, sem colaborador em vermelho).
- Som (Web Audio, `OscillatorNode` de 150 ms): novo → `som_hz` do colaborador; sem colaborador → 2 bipes de 150 Hz; repetido → 2 bipes de 220 Hz. Na primeira carga, mostrar botão `Ativar som` que cria o `AudioContext` (exigência do navegador).
- A página nunca prende o foco do teclado de propósito; o bip vai para o UpSeller.
